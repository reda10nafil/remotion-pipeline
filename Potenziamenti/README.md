# Potenziamenti Installati

1. **Remotion** (`npx create-video@latest`):
   - Framework video in React (versione 4.0.525), Tailwind CSS v4, TypeScript.

2. **Server MCP Ruflo**:
   - Pacchetto npm `ruflo@latest`.
   - Configurato in `mcp_config.json`.

3. **Server MCP Blender**:
   - Pacchetto `mcp-for-blender` (attivo su porta 9876).
   - Addon Blender aggiornato su disco e registrato in `mcp_config.json`.

4. **Server MCP 21st.dev Magic**:
   - Pacchetto npm `@21st-dev/magic-mcp-server`.
   - Configurato in `mcp_config.json`.

5. **Skill UI/UX Pro Max**:
   - Pacchetto CLI `uipro-cli`.
   - Skill con template, regole e script in `skills/ui-ux-pro-max/`.

6. **Skill Impeccable**:
   - Repository `pbakaus/impeccable`.
   - Skill con regole anti-slop e comandi in `skills/impeccable/`.
